Q1.3 DELETE
--------------------------------------------------------------------------------
(a) Delete one dependent and one WORKS_ON row:
DELETE FROM DEPENDENT
WHERE essn = 101 AND dependent_name = 'Mariam';
-- Query OK, 1 row affected (0.00 sec)

DELETE FROM WORKS_ON
WHERE essn = 106 AND Pno = 20;
-- Query OK, 1 row affected (0.00 sec)

(b) Try to delete a department that still has employees:
DELETE FROM DEPARTMENT
WHERE Dnumber = 1;

Error message:
ERROR 1451 (23000): Cannot delete or update a parent row: a foreign key constraint fails
(`company`.`employee`, CONSTRAINT `fk_emp_dept` FOREIGN KEY (`Dno`) REFERENCES `department` (`Dnumber`))

Explanation & Order of changes:
MySQL prevents deleting parent rows that are currently referenced by child records without CASCADE.
To delete department 1, you must remove or reassign all references in the following order:
1. Reassign or delete all employees referencing Dno = 1:
   - If deleting employees, first delete their dependent records (`DEPENDENT`), their assigned projects (`WORKS_ON`),
     and reassign any department managers (`mgr_ssn`) or supervisor references (`super_ssn`).
   - Or simply reassign them: `UPDATE EMPLOYEE SET Dno = NULL WHERE Dno = 1;` (or assign to another department).
2. Reassign or delete all projects referencing Dno = 1:
   - First remove `WORKS_ON` rows for those projects: `DELETE FROM WORKS_ON WHERE Pno IN (SELECT Pnumber FROM PROJECT WHERE Dno = 1);`
   - Then delete or reassign projects: `UPDATE PROJECT SET Dno = NULL WHERE Dno = 1;` or `DELETE FROM PROJECT WHERE Dno = 1;`
3. Finally, delete the department: `DELETE FROM DEPARTMENT WHERE Dnumber = 1;`

(c) Transaction demonstration:
START TRANSACTION;
DELETE FROM DEPENDENT;
SELECT * FROM DEPENDENT;
ROLLBACK;
SELECT * FROM DEPENDENT;

Output during transaction:
Empty set (0.00 sec)

Output after ROLLBACK:
+------+----------------+--------+------------+--------------+
| essn | dependent_name | gender | bdate      | relationship |
+------+----------------+--------+------------+--------------+
|  101 | Kareem         | M      | 2015-02-10 | Son          |
|  102 | Nour           | F      | 2019-11-23 | Daughter     |
+------+----------------+--------+------------+--------------+
2 rows in set (0.00 sec)

Explanation:
`DELETE FROM DEPENDENT;` without a `WHERE` clause removed all records from the `DEPENDENT` table
within the temporary uncommitted transaction context.
`ROLLBACK;` canceled the entire active transaction, restoring the database state to what it was
before the transaction began. All deleted rows were fully restored.

Q1.7 HAVING
--------------------------------------------------------------------------------
(a) The departments that have more than 2 employees:
SELECT Dno, COUNT(*) AS employee_count
FROM EMPLOYEE
WHERE Dno IS NOT NULL
GROUP BY Dno
HAVING COUNT(*) > 2;

Output:
+-----+----------------+
| Dno | employee_count |
+-----+----------------+
|   1 |              3 |
+-----+----------------+
1 row in set (0.00 sec)

(b) Do the same, but count only the employees whose salary is above 3000:
SELECT Dno, COUNT(*) AS employee_count
FROM EMPLOYEE
WHERE Dno IS NOT NULL
  AND salary > 3000
GROUP BY Dno
HAVING COUNT(*) > 2;

Output:
+-----+----------------+
| Dno | employee_count |
+-----+----------------+
|   1 |              3 |
+-----+----------------+
1 row in set (0.00 sec)

Explain in one sentence the difference between WHERE and HAVING:
WHERE filters individual rows before grouping or aggregation occurs, whereas HAVING filters aggregated groups after the GROUP BY operation has taken place.

Q1.12 JOIN + GROUP BY + HAVING
--------------------------------------------------------------------------------
For each project: its name and the total hours worked on it, only for the projects
with more than 20 hours, largest total first:

SELECT 
    p.Pname AS project_name,
    SUM(w.hours) AS total_hours
FROM PROJECT p
JOIN WORKS_ON w ON p.Pnumber = w.Pno
GROUP BY p.Pnumber, p.Pname
HAVING SUM(w.hours) > 20
ORDER BY total_hours DESC;

Output:
+--------------+-------------+
| project_name | total_hours |
+--------------+-------------+
| ProductY     |        37.0 |
| ProductX     |        33.0 |
+--------------+-------------+
